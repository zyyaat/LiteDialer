# Lite Dialer 📞

تطبيق اتصال (Dialer) خفيف وسريع مصمم خصيصًا للأجهزة الضعيفة — مبني ومُختبَر ليعمل بسلاسة على **Samsung Galaxy A10** (رام 2 جيجا).

- **اللغة:** Kotlin (بدون أي مكتبات ثقيلة — 2 dependencies فقط)
- **حجم الـ APK المستهدف:** أقل من 3 ميجا
- **minSdk 28** (أندرويد 9) — يعمل تلقائيًا على كل الأجهزة الأحدث
- واجهة Views تقليدية (بدون Compose) لأسرع بدء تشغيل وأقل استهلاك رام

## المميزات

- سجل المكالمات مع أيقونات (واردة / صادرة / فائتة) وصور رمزية بحرف الاسم (بدون تحميل صور = صفر تأخير)
- الاتصال بضغطة واحدة على أي سجل
- لوحة أرقام مع اقتراحات فورية من جهات الاتصال أثناء الكتابة (بعد خانتين)
- شاشة مكالمة كاملة: رد / رفض / إنهاء + كتم + سماعة + لوحة أرقام DTMF للرد الآلي
- إشعار مستمر أثناء المكالمة + شاشة المكالمة تظهر فوق شاشة القفل
- صفر خدمات في الخلفية — التطبيق لا يستهلك بطارية إلا وقت المكالمة

## الحصول على الـ APK

### الطريقة التلقائية (GitHub Actions)
1. كل ضغطة (push) على الريبو يبني الـ APK تلقائيًا: افتح تبويب **Actions** → آخر تشغيل → حمّل **LiteDialer-APK**.
2. أي tag يبدأ بـ `v` (مثل `v1.0`) يبني وي نشر الـ APK في **Releases** مباشرة.

### البناء محليًا
```bash
# افتح المجلد في Android Studio واضغط Run، أو من الطرفية:
gradle assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```

> ملاحظة: نسخة الـ release موقعة حاليًا بمفتاح debug حتى تكون قابلة للتثبيت فورًا. قبل النشر على متجر Play أنشئ keystore خاصًا واستبدل `signingConfigs.debug` في `app/build.gradle`.

## التثبيت على Samsung A10

1. انقل ملف الـ APK للهاتف وثبّته (اسمح بـ "مصادر غير معروفة" لو طلب).
2. افتح التطبيق → اسمح بأذونات **سجل المكالمات** و**جهات الاتصال** و**الاتصال**.
3. اضغط **تعيين كتطبيق الاتصال الافتراضي** واختر Lite Dialer — من هذه اللحظة أي مكالمة (واردة أو صادرة) ستظهر بشاشة التطبيق.
4. (مستحسن) راجع إعدادات البطارية واسمح له بالعمل بلا قيود حتى لا يمنعه النظام من الرد على المكالمات.

## البنية التقنية

```
app/src/main/java/com/lightdialer/
├── MainActivity.kt          # سجل المكالمات + طلب الأذونات + تعيين التطبيق الافتراضي
├── DialpadActivity.kt       # لوحة الأرقام + الاقتراحات
├── CallLogAdapter.kt        # عرض سجل المكالمات
├── call/
│   ├── InCallServiceImpl.kt # مربوط بالنظام وقت المكالمة فقط (InCallService)
│   ├── InCallActivity.kt    # شاشة المكالمة الجارية
│   ├── ActiveCallManager.kt # إدارة مكالمات النظام الحية
│   └── OngoingCallNotifier.kt
├── data/
│   ├── CallLogStore.kt      # قراءة سجل المكالمات (بخيط خلفي + تقسيم)
│   └── Contacts.kt          # أسماء المتصلين + الاقتراحات
└── util/                    # أدوات مساعدة صغيرة
```
